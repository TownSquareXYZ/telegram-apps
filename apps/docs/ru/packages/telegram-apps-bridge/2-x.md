Самый нижний уровень связи с мини-приложениями Telegram.

Этот пакет содержит фундаментальные утилиты и типы для разработки приложений на платформе Telegram Mini Apps.

Хотя разработчик может использовать только этот пакет, рекомендуется использовать пакет более высокого уровня например [@telegram-apps/sdk](telegram-apps-sdk/2-x).

## Установка

::: code-group

```bash [pnpm]
pnpm i @telegram-apps/bridge
```

```bash [npm]
npm i @telegram-apps/bridge
```

```bash [yarn]
yarn add @telegram-apps/bridge
```

:::

## Использование

Вот базовый пример использования этого пакета. Подробнее см. в следующих статьях документации.

```ts
import { on, postEvent } from '@telegram-apps/bridge';

// Покажите кнопку "Назад", дождитесь, пока ее щелкнут один раз,
// затем скройте ее.
postEvent('web_app_setup_back_button', { is_visible: true });

const off = on('back_button_pressed', () => {
  postEvent('web_app_setup_back_button', { is_visible: false });
  off();
});
```
